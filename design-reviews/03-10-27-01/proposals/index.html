Edit content in place — updated October 8

Intentional entry, one section: choose Edit section or Edit section here. Type, replace, paste and format directly in rendered headings, paragraphs, lists, tables and literal code within the existing document scroll surface. A named section boundary identifies the editing scope; surrounding content remains readable and read-only.

Formatting appears contextually on selection or a block-action request. Keyboard and contextual routes retain the selection and restore the caret when dismissed. No raw Markdown pane, separate preview, source/preview toggle or split editor. Literal code is document content; conflict inspection is a separate read-only recovery task.

  • Save and Save As: explicit Save returns to reading only after acknowledgment. Save As retains its existing Save a copy semantics and leaves the original dirty. Cancellation or failure preserves the draft. Unsaved and recovery acknowledgments remain distinct.
  • Dirty exits and conflicts: retain Save / Keep draft / Discard / Cancel guards and revision-aware recovery. Disk conflict blocks original Save and keeps Inspect versions / Keep my edit / Save a copy / confirmed Use disk version. See state board 15.
  • Undo/Redo and recovery: preserve source-backed draft transactions, selection and existing schema1 history/recovery. No cross-save Undo promise is added.
  • Opaque constructs: preserve Mermaid, YAML, raw HTML and unknown constructs with their original bytes and safe presentation. Refuse unsafe splits, conversions, deletion or movement with a construct-specific explanation; preserve draft and selection. No source-editor fallback.

CRLF Save remains DEFERRED. The recorded user deferral is unchanged; non-LF authoring remains guarded. No fix, successful CRLF acceptance or reopened gate is inferred.

Evidence and limits: the implementation finish report records delivered editing and separate focused/native checks, with unresolved broader regression failures. Final packaged journeys, physical IME, VoiceOver and the full theme/locale/size matrix remain NOT TESTED end-to-end. Platform/visual acceptance is incomplete and user acceptance pending.
