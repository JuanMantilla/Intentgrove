# Intentgrove

Intentgrove is a calm document workspace for reading, organizing, and refining
documents exchanged with AI. Its purpose is to help people understand AI output
and prepare clearer context for communicating with AI. The name combines intent
with the sense of a quiet grove and leaves room for formats beyond Markdown.

The confirmed direction is calm and distinctive, like a reading space. AI is
central to the product's purpose; this naming decision does not add built-in
chat, model integrations, accounts, or cloud services.

Proposed tagline: *A clearer conversation with AI.* The tagline remains a copy
proposal; the user selected the product name.

The name is applied to the app/window title, frontend package metadata, native
package description, macOS app/DMG outputs, QA bundles, and current product
documentation. Existing binaries need a rebuild to display the new name.

The repository folder, Rust crate/binary names, bundle identifiers, storage keys,
and recovery locations retain their existing technical identities. Historical
specifications, approval snapshots, fixtures, and verification evidence retain
their original names and hashes. Domain and trademark availability have not
been verified.
