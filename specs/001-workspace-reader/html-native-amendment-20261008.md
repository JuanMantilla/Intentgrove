# Standalone HTML native architecture and verification contract

Authorization: October 6 remaining scope, reaffirmed October 8. Owning requirements F001-H01–H08. This extends the existing canonical feature; it creates no new selected feature, editing format or approval snapshot. Installed Spec Kit prerequisite workflow resolves F001 using `SPECIFY_FEATURE_DIRECTORY=specs/001-workspace-reader SPECIFY_FEATURE_NO_PERSIST=1`; global feature013 is unchanged. Existing F001 requirement-quality checklist14/14 checked. No extension hooks file exists.

Shared Tauri command host owns descriptors/grants/requests and a bounded native HTML service. Documents never use Tauri WebviewBuilder, main DOM/iframe/srcdoc, image XPC or diagram pixels as a viewer. macOS standalone WKWebView: content JS disabled, fresh process pool, ephemeral website data store, no user scripts/message handlers, app inspection in defaultClient content world, response CSP plus precompiled network content blocker. Native navigation/UIDelegates reject unsolicited navigation, popups/downloads/media permission. Native overlay bounds are workspace-client coordinates and must be hidden during shell overlays, Settings and resize. Windows standalone Wry/WebView2 adapter uses script/web-message/host-object denial, all-request response interception, CSP, explicit navigation/frame/permission/download/new-window handlers and no Tauri initialization. Windows source is unverified without Windows target/runtime; never count Mac compilation as Windows evidence.

Broker uses current native root/file authority on every read. It checks source identity/stamp, resource identity/stamp before/after reads, no-follow paths, UTF-8 HTML/CSS, static font signatures and embedded raster dimensions. Author base is denied by CSP; resource URLs use a view-specific virtual origin. Relative/root-relative broker URLs remain inside granted scope. Absolute/file and remote resource URLs are blocked rather than silently translated into filesystem authority. Explicit-file virtual URL paths preserve full volume-relative ancestry *as naming coordinates only*, never a volume/ancestor grant. This retains ../ references while requiring deliberate matching asset selection. Root-granted URLs remain workspace-relative; workspace-escaping and cross-volume/file-URL references are unsupported. Per-view resource folder/file selections are independent retained opened handles; file selection must match the requested resource. Folder selection cannot replace workspace root. Reselection/reload revalidates all assets.

Budgets:16 live views,16 pending opens,32 asset selections/view, HTML4MiB UTF-8;128 resource requests/load; CSS1MiB each/4MiB cumulative; static imports depth8/cycles rejected; fonts8MiB cumulative and supported signatures; compressed image16MiB; 32MP/frame,100 frames,128MiB estimated decoded aggregate; all resources64MiB;5s broker/load deadline; operation reply deadline6s; URLs4096 bytes, diagnostics128/2048 chars, headings1000/2048 chars, Find256-byte query/2Mi UTF-16 index/100000 visited text nodes/10000 matches. Escaped or unrecognized CSS import syntax is unsupported rather than bypassing depth enforcement. A shared pure-Rust container/header preflight admits PNG/JPEG/GIF/WebP, bounding dimensions, frame count and estimated decoded bytes before engine-process decoding. No host image decoder is invoked. The existing Windows standalone-image worker is not repurposed.

SVG: external SVG MIME/resources, object/embed/frames and media are denied. Inline SVG presentation remains browser-rendered under script-off/CSP; no external SVG document is served. Font parsing and HTML layout happen in the engine process. Host resource reads/container headers are bounded, but no claim of a hard OS memory quota or forced WebContent process termination is made. Disposal revokes broker state, cancels load, releases native views/delegates/observers/timers/assets and rejects late callbacks; WebKit owns shared subprocess lifetime.

Native refresh fingerprinting admits HTML through stable125ms double reads and existing refresh notices. `get_confirmed_document` remains Markdown-only. Frontend uses HTML descriptor replacement/mount and location capture, not Markdown confirmed text. `get_html_state` detects opened resource/source changes; frontend must poll active HTML state and reload through the HTML path. Resource folder changes are not independent OS watchers in this implementation. Session schema1 adds optional htmlZoom/htmlScrollLeft fields to existing anchors and reports restored kind; absent fields default at the consumer. HTML editing/recovery payloads are refused.

Native-to-frontend API and exact error/flow semantics: [handoff](../../os-engineering/html-frontend-handoff.md). Verification and candidate identities: [native evidence](../../os-engineering/evidence/html-native-20261008/). Approval is not acceptance.

Unstyled typography: optional mount baseline uses current Reading font/size/line-height, defaulting to bundled Roboto16/1.6. Style elements/attributes or stylesheet links conservatively suppress injection, preserving authored canvas/inheritance. App font assets are compiled immutable presentation resources, charged to font/request/total budgets; no user filesystem authority is inferred. Real screenshot pixel regression detects the earlier fallback white-gutter defect.

Final budget accounting: reserve filesystem resource length plus one bounded growth-guard byte before reading; failed decoding/UTF-8/font/import validation still consumes the64MiB aggregate and relevant CSS/font budgets. Import declarations are capped at128 across all stylesheets before allocating resolved graph edges, including remote imports. Diagnostic display URLs are truncated to2048 characters while full ≤4096-byte broker URLs remain private and keyed by diagnostic ID for exact-file selection. Read admission expires5s after descriptor creation; blocking OS reads are cooperatively revoked, not forcibly interrupted. Source failure preserves the broker reason code.

CSS graph validation memoizes completed (URL, depth) pairs across roots; repeated import edges cannot expand into exponential traversal. The128-declaration/depth8 bounds limit retained graph and validation work. The native regression includes eight levels with fifteen repeated imports per level.

Pre-engine presentation policy: parse source with dom_query0.27.0/html5ever0.38.0 in scripting-disabled mode; remove every link element except a sole case-insensitive stylesheet relation, and remove meta refresh. This removes DNS/preconnect/prefetch/preload/modulepreload/prerender/icon hints before the engine can speculate. Alternate/multiple-relation stylesheets are unsupported. Source bytes/hash on disk remain untouched; presentation HTML is normalized by an HTML parser, so DOM normalization may affect malformed markup. Limit100000 raw markup-open delimiters and8MiB serialized presentation, in addition to4MiB UTF-8 source. macOS responses also send X-DNS-Prefetch-Control:off. A loopback connection reset in an earlier HTTP-only observation prompted TCP-accept instrumentation; final evidence requires exactly the two positive-control connections as well as zero document HTTP requests. The earlier reset is retained in before-hint-removal-connection-reset.log; attribution to a specific hint was not established. This is still not arbitrary-hostname/DNS packet capture.

Final pre-engine policy additionally removes base/iframe/object/embed and all http-equiv meta elements. Absolute/protocol-relative URL attributes (href/src/action/formaction/data/poster/background/codebase/archive/manifest) are stripped after HTML entity parsing and ASCII whitespace normalization; ping/attributionsrc/srcset are unsupported and removed. Local relative links, fragment links, src images, sole-relation stylesheets and inline CSS remain; inline scripts/event handlers remain inert under engine JavaScript denial. This deliberately makes external/executable links noninteractive; their original URLs remain bounded remote diagnostics where detected. The hint-only candidate still produced four extra loopback TCP accepts and was rejected (hint-only-tcp-failure.json/log); no specific element attribution is claimed.
