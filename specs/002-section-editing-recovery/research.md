# F004 Phase 0 Research

**Date**: 2026-09-26. Decisions below support [plan.md](plan.md); they do not authorize implementation.

## Decisions

| Topic | Decision and reason | Alternatives considered |
|---|---|---|
| Source section authority | Use native `pulldown-cmark` offset iteration over confirmed UTF-8 bytes. Bind each nonoverlapping section to original byte offsets and disk version. Rendered remark headings must match; fail closed on mismatch. This lets native Save validate exactly which bytes may change. [Parser offsets](https://docs.rs/pulldown-cmark/0.13.4/pulldown_cmark/struct.OffsetIter.html). | Frontend-only offsets are easier but leave the write boundary client-controlled. Heading slugs are ambiguous after duplicate/renamed headings. |
| BOM and Unicode | Remove the optional BOM before remark parsing, track its byte prefix separately, and convert UTF-16 frontend positions to UTF-8 only for comparison. Local probes found remark positions align for CRLF and emoji but shift by one JS code unit with an initial BOM. Test setext headings, fenced/quoted/list text, CRLF, CR, and multibyte characters. | Raw remark positions with BOM can select the wrong source byte. |
| Editor | Use modular CodeMirror 6 packages, direct extensions, `historyField` serialization, and explicit line separator. Store scroll offsets separately. [CodeMirror reference](https://codemirror.net/docs/ref/), [extensions](https://codemirror.net/docs/extensions/). | `basicSetup` adds controls outside this focused editor; a textarea loses reliable undo/redo restoration. |
| Recovery | Keep one bounded, versioned, checksum-protected checkpoint per document in Tauri per-user app data. Acknowledge only after durable temp write, sync, replacement and parent sync. Preserve previous valid checkpoint until next acknowledgment. [Tauri path resolver](https://docs.rs/tauri/latest/tauri/path/struct.PathResolver.html), [Rust File sync](https://doc.rust-lang.org/std/fs/struct.File.html). | Browser localStorage and repository sidecars lack the needed durability, scope, or privacy model. CodeMirror history minimum depth is not a storage cap; enforce record-size bounds and show failure. |
| Save conflict | Check baseline disk version at Save start and immediately before commit, stage complete composed bytes, retain recoverable original, replace atomically, verify after commit, and keep draft until success. User chose practical protection with disclosed race: arbitrary other apps do not participate in an atomic compare-and-replace protocol. [Apple replacement API](https://developer.apple.com/documentation/foundation/filemanager/replaceitemat%28_%3Awithitemat%3Abackupitemname%3Aoptions%3A%29), [Rust create_new](https://doc.rust-lang.org/std/fs/struct.OpenOptions.html). | Advisory locks alone cannot constrain uncooperative writers. Existing delayed `confirmed_bytes` is unsuitable as the immediate final check. |
| Save As | Native dialog chooses explicit destination. Compose a full copy from the draft's base snapshot and changed section even if the original has since changed; never silently merge. Create new destination exclusively, or require explicit replacement confirmation and recheck the existing destination. [Tauri dialog](https://tauri.app/plugin/dialog/). | Reusing original Save would risk replacing the conflicted source. |
| Quit | Intercept window close in Rust and route Cmd+Q through the same prompt. Treat Dock/system Quit as a feasibility gate requiring a native macOS delegate bridge and packaged proof. Tauri's `ExitRequested` is insufficient for that path according to [Tauri issue 9198](https://github.com/tauri-apps/tauri/issues/9198); Apple's [termination delegate](https://developer.apple.com/documentation/appkit/nsapplicationdelegate/applicationshouldterminate%28_%3A%29) supplies the required decision point. | JS `onCloseRequested` alone and app-menu replacement alone do not cover Dock Quit. |
| Workspace restore | F003C owns folder grant, tabs/order, active tab, panel layout and reader positions. F004 extends its session record with editor mode/draft. F003C is draft and must be separately approved and implemented before exact F004 restoration can pass. | Duplicating F003C under F004 would silently expand approved scope and risk two competing session systems. |

## Open implementation proof, not an unspecified product decision

- The macOS native termination bridge must be shown to coexist with Tauri/Tao in a packaged app before closing F004-R08. If it fails, revise the architecture and affected approvals.
- Exact CodeMirror package versions are resolved and pinned with the lockfile at implementation; the planning environment's npm registry was unreachable. This does not change the chosen editor or user behavior.
- The durable checkpoint byte cap and history pruning algorithm must be quantified from a fixture and stress run before enabling editing. A cap failure is a visible unsafe-to-quit state, never a silent truncation.
- The residual race is disclosed in Save help/error copy. A foreign write after the final check can be overwritten before its bytes are captured, so no absolute cross-process guarantee is claimed.
