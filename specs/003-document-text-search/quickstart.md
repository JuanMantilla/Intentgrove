# F003S verification guide

Use a disposable folder and packaged macOS app; keep before/after hashes. Prepare repeated terms across headings, tables, code, links, hidden syntax, offscreen sections, accents and non-BMP text; add a second tab and section draft.

1. Check AS-001/003–007 with Command+F, Enter, Shift+Enter, Escape and tab switch without a mouse. Record count/order and active indication.
2. Change a file externally and an unsaved draft. Check AS-008, stale decorations and draft integrity.
3. Check empty, whitespace, absent, unreadable and over-limit states, EN/ES labels, focus and 640-point layout.
4. Observe app-request attempts during Find and compare hashes for AS-009; state observer coverage. Missing console output is not evidence of no requests.
5. Time ten warm 1 MiB trials on a named Mac/build for SC-002. Record raw timings and 9/10 threshold. Run SC-001 user trial separately if participants are available.

Use PASS/FAIL/BLOCKED/NOT TESTED per scenario/criterion. Windows/Linux Control+F is NOT TESTED until supported builds exist.
