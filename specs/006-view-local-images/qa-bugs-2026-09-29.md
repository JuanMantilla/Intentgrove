## Checks without a new product failure

- **PASS, helper only:** SVG basic shapes, PNG, JPEG, GIF, WebP, BMP, TIFF and HEIC/HEIF returned decoded pixels; disposable source hashes stayed unchanged. Small raster pixels were visually checked against their solid-color fixtures, including WebP against a separate `sips` conversion ([outputs](evidence/qa-raster-pixels/)). JPEG claimed as PNG returned `mismatch`; script and embedded-data SVGs returned `unsafe_or_corrupt`.
- **PASS, component only:** four focused UI test files, 30 tests. These mock native image responses and do not verify SVG text pixels.
- **NOT TESTED:** Full packaged tree/picker/inline journeys, visual zoom/keyboard/layout, app-request observation, external writer, helper fault injection and end-to-end latency/memory. There is no isolated visible app window or production request observer in this session. The user's specific app observation establishes QA-01's symptom but does not verify those other journeys.

The code review and Spec Kit cross-artifact check found that T016/T020 covered SVG decode status and hostile content but had no rendered-text or generic-font fidelity check. Follow-up tasks T022–T026 in `tasks.md` trace these findings. Production code was not changed in this QA pass.
