# IR-05 native amendment — 2026-10-06

Authority: the explicit IR-05 IMPLEMENT request and the native integration approvals in `docs/approvals.md`. This supplement reconciles F003F R02/R06–R09 and shared workspace navigation; original approval snapshots and outstanding packaged acceptance tasks remain intact. Installed Spec Kit resolved F007W globally and F003F through its explicit non-persisting feature-directory override; see `os-engineering/evidence/ir05/spec-kit.txt`.

Specification: `start_folder_search` additionally accepts optional `scopeSegments: string[]`; omitted, null or empty selects the existing grant root. Components are literal root-relative names, never a path string or new grant. Confirm a directory with existing no-follow native adapters, reject invalid/deep paths, files and links/reparse points, and return `{jobId, generation, scopeSegments}`. Every hit retains root-relative segments. Root generation and confirmed directory identity constrain traversal, emission and open. Replaced scope returns `scope_changed`; expired root/job returns `invalid_grant` (a replaced selected root pathname may return `root_reselection_required`). Root search, ancestor/local ignore rules, includeIgnored, budgets and cancellation remain compatible. Stop preserves already collected hits; replacing a job expires its hits and in-flight opens.

Architecture: retain an identity-bound directory handle per job; all result files and descendant directories open relative to it after checking the current root and scope. Reuse document stable-byte/identity checks with the already scoped file handle and check the scope/job again before returning. Do not re-open the content solely through a renderer path. Load ancestor ignore files through the original grant in root-to-scope order. An ignored ancestor remains pruned unless includeIgnored is selected, matching root traversal.

Shared navigation contract: macOS adds a Go submenu with `go_back`, `go_forward`, `go_visited`, `go_clear`; all accelerators are unassigned. Deliver existing `native:menu` to `main`. Settings focus suppresses workspace/Go actions. Extend native menu state with optional `back`, `forward`, `visited`, `clearHistory` booleans, omitted values disabled. The committed client history remains the only history owner, including guards, failed traversal, closed-tab reopen and clear-current retention. Windows retains client Go and explicit unsupported native-menu state.

Experience: existing approved Go/history experience is reused. Subtree scope is distinct from Names/Contents/Both, and must display the native-confirmed scope. Frontend folder action/panel integration is handed off separately; this native delivery does not claim that disabled narrower-search UI is already enabled.

Verification: disposable native fixture and client-event regressions; native macOS menu/runtime and packaged scoped-search acceptance require their own host. Exact implementation, errors, checks and remaining integration are in `os-engineering/ir05-report.md` and `os-engineering/ir05-frontend-handoff.md`.
