# F003F verification guide

Build a disposable 25,000-entry root with 5,000 Markdown files, nested `.gitignore`, ignored/unignored hits, symlinked ignore file pointing outside root, missing/denied files, Unicode and changed results. Keep hashes. In a packaged Mac app, run name/text, include-ignored, zero/empty, Stop, query/root switch, changed-result open and EN/ES keyboard journeys. Record every result/skip against a fixture manifest; observe app-request attempts and hashes. Time ten cancellation trials with raw values and host/build details.
